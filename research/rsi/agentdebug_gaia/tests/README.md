# Sealed verifier requirements

Create this image separately from the agent image after receiving the official
authoring kit. Store real hidden inputs outside the public source repository.
Only submitted method code crosses the seal; saved answers are not submissions.

Execute code in an OS-isolated environment without readable labels, other cases,
host credentials or arbitrary network. Pass only the current gold-free case and
an approved model capability. Freeze the output before the trusted controller
loads labels and computes the fixed-denominator metric. Apply the same call,
token, timeout and retry budgets used for visible feedback.

The pure functions under `scripts/rsi_exam/` are prototype validation helpers,
not a secure executor or finished official `grade.py`. Test filesystem leakage,
child-process/environment leakage, code modification of the evaluator, malformed
outputs, duplicates, missing cases, case-ID memorization and cross-case caches.
Finally calibrate the unchanged starter and optional reference under this exact
harness and keep a reproducible audit of the normalized baseline score of zero.
