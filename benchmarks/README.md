# Benchmark identities

`cohorts/` contains explicit case-selection manifests used by benchmark tools.
It is not a download of AgentErrorBench and does not include raw trajectories
or a private test set.

The selected GAIA result concerns AgentErrorBench's processed failure traces,
not success on the original GAIA questions. Case-set, file, and semantic hashes
serve different purposes; retain the exact identities when comparing results.

See [Evaluation](../docs/results/README.md),
[Reproduction](../REPRODUCING.md), and
[Data provenance](../docs/data-provenance.md) before obtaining or redistributing data.
