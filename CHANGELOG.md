# Changelog

## Unreleased

### Supported method and compatibility

- Unified public diagnosis under AgentDebug with fixed GPT-5.5 / medium,
  a chronological anchor, one later challenger, and conservative arbitration.
- Routed the public command, compatibility executable names and Python API to
  the selected prompt builders and validators; removed public method selectors.
- Added explicit preparation, bounded fresh-session execution, strict stage
  audits and write-once run directories.
- Diagnosis now takes gold-free processed GAIA manifests. General trace ingestion
  and integrity checking remain available; the former session/judge diagnosis
  contract is retired to the restorable source archive.
- Preserved saved results and frozen implementation hashes. The standalone
  adapter has no new measured accuracy result.

### Documentation and maintenance

- Physically separated historical scripts, modules, tests, configurations and
  diaries into a verified source snapshot; current runtime imports no research
  or repository scripts. Kept browsable results under the research gateway.
- Extracted the selected protocol into neutral modules with explicit source
  mapping; whole-stage tests check prompts and validators after declared
  executable-path changes. Original source and result hashes are preserved.
- Added archive restoration and stale-distribution-content regression tests.

- Added non-mutating local commit hooks and a review-only commit inventory with
  source hashes, inherited deletions and local-history key-pattern scanning.
- Moved archive-only Make targets out of the public Makefile.
- Added installed-wheel CLI smoke checks to CI.
- Repaired current archival code-bundle dependency lists and explicit legacy
  test imports after public API consolidation, without changing frozen results.
- Reorganized user documentation around installation, architecture, commands,
  evaluation, and reproducibility.
- Added synthetic quick-start checks, documentation-link validation, and
  distribution-content checks.
- Separated normal contributor checks from optional research/archive checks.
- Added contribution, security, issue, and pull-request guidance.

This is a source-checkout change log, not a claim that a tagged release or
package upload has occurred. Original frozen diagnostic rules and recorded
scores are unchanged; the public defaults, API and execution adapter have changed.
